A single funny line — an AI writing its owner's dating profile as if it were a software disclaimer — written to `/output/entry.txt` by a tiny TypeScript program for make.fun's One Line, One Laugh.

## The entry

> My AI wrote my dating profile: 'Open source, no warranty, may hallucinate love.'

80 characters, one line. The joke is built on a clash everyone who uses AI already knows: the model disclaims everything, even the one thing a dating profile is supposed to promise. "Open source, no warranty" reads like a software license, and "may hallucinate love" turns the model's most famous failure mode into a romantic warning — the punchline lands on the last word, and the whole line reads cleanly in one pass.
